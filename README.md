Explainable Phishing Email Detector

## Project Overview

This project is being developed for ICT932 – Cybersecurity Testing and Assurance Assessment 3.

The project implements an Explainable Phishing Email Detector that analyses email content and metadata to identify potentially malicious phishing emails and provides human-readable explanations for its decisions.

## Project Objectives

The system will provide:

- Secure user authentication
- Role-Based Access Control (RBAC)
- Two-Factor Authentication (2FA)
- Safe email parsing
- Sender and email-header analysis
- URL and domain analysis
- Rule-based phishing detection
- Machine-learning phishing classification
- Explainable risk scoring
- Zero Trust email ingestion
- Quarantine simulation
- Analyst feedback and false-positive review
- Dashboard and detection statistics
- PDF, CSV and JSON reporting
- Automated security testing using DevSecOps practices

## Ethical Testing

All phishing samples, malicious URLs and attack scenarios used in this project will be synthetic, authorised or obtained from appropriate research datasets.

The system will not be used to target real individuals, organisations or unauthorised systems.
