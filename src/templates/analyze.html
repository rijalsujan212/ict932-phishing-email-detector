Zero Trust Ingestion

Analyze an Email

Every input is treated as untrusted. URLs are never opened and attachments are hashed, not executed.

Upload

Permitted: .eml or .txt. Maximum size: 1 MB.

What the system checks

  • File type and size validation
  • Sender / Reply-To mismatch
  • SPF, DKIM and DMARC evidence
  • Suspicious and look-alike domains
  • Redirect-like URL parameters
  • Offline threat-intelligence list
  • Suspicious phishing language
  • Attachment metadata and SHA-256
  • TF-IDF + Logistic Regression classifier
  • Human-readable explanations

Safe demonstration files

Use files from data/samples/:

  • phishing_sample.eml — designed to produce a high phishing score.
  • legitimate_sample.eml — normal legitimate message.
  • blocked_sample.exe — safe text content with a forbidden extension to demonstrate Zero Trust blocking.
